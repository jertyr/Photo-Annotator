# Feedback

The running record of what actually landed. This file, not the topic queue, is the
strongest signal for what to write next. The research Routine reads it on every run.

Two ways things get here:

1. **From the app.** Rate an episode in the reader ("More of this" / "Fine" / "Not
   for me") or type a request into the idea box. Tap "Send to Tangents" and it opens
   a pre-filled GitHub issue titled `[feedback] ...`. Submit it and you are done.
2. **By hand.** Edit this file directly. Anything written here counts.

The Routine folds open `[feedback]` issues into the lists below, then closes them,
so this file stays the single source of truth.
